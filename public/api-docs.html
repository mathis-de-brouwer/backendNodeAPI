User Management News Management API Documentation

API Documentation

Users Endpoints

GET /api/users

Get all users with pagination support.

Query parameters:

  • limit (optional): Number of records to return (default: 10)
  • offset (optional): Number of records to skip (default: 0)
GET /api/users/:id

Get a specific user by ID.

POST /api/users

Create a new user.

Required fields:

  • name (string): User's name (cannot contain numbers)
  • email (string): User's email address
  • password (string): User's password
PUT /api/users/:id

Update an existing user.

DELETE /api/users/:id

Delete a user.

GET /api/users/search?q=term

Search users by name or email.

News Endpoints

GET /api/news

Get all news articles with pagination support.

Query parameters:

  • limit (optional): Number of records to return (default: 10)
  • offset (optional): Number of records to skip (default: 0)
GET /api/news/:id

Get a specific news article by ID.

POST /api/news

Create a new news article.

Required fields:

  • title (string): Article title
  • content (string): Article content
PUT /api/news/:id

Update an existing news article.

DELETE /api/news/:id

Delete a news article.

GET /api/news/search?q=term

Search news articles by title or content.
